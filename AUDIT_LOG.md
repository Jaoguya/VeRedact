# AUDIT_LOG — VeRedact-PQ evaluation code

Correctness findings in the evaluation code and how each was fixed (A1–A9 were found against the previous manuscript
and still hold; since 2026-10-24 the reference is `Overleaf/VeRedact-optimize.tex`). Rules: no fabricated or tuned
numbers, every discrepancy listed with evidence, all compute on the AWS server, no capped figure lines. Diagnostic
scripts named as evidence (`profile_round.py`, `validate_a3.py`, `validate_provers_loopback.sh`,
`diag_core_isolation.py`) were removed on 2026-11-01 and remain in git history.
