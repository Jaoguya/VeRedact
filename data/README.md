# Data

There is no downloaded or raw data. The evaluation uses one **synthetic enterprise ledger** and one
**redaction-request trace**, generated deterministically from `meta.seed` (configs/base.yaml) by
`src/veredact_bench/data/dataset.py`:

| Item | Generated from | Config |
|:--|:--|:--|
| Ledger: transactions with random payloads (256 B – 4 KB), owner, policy, timestamp | `random.Random(seed)` | `configs/datasets/synthetic_ledger.yaml` |
| Trace: Poisson arrivals, Zipf-distributed target batches, fault injection | `random.Random(seed)` | `configs/base.yaml` (`workload`) + each experiment's rate / skew |

Every method receives the same ledger and trace for a given (seed, tier, experiment point); the dataset's
digest (`dataset_id`) is written to each run's `run_info.json`, so two runs can be checked to have used the
same data. License: generated by this repository, no third-party data. Nothing is cached on disk except the
PQCH committee keys (`.cache/pqch_dkg/`, gitignored), which are a pure function of (seed, n, t, lattice
parameters).
